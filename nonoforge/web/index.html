    How this works

    1. Pick a card. Each card is a small, complete app — not a mock-up, not a starter kit with the interesting parts missing.

    2. Answer a couple of questions. Your name, a colour, maybe drop in a few photos. Plain questions only.

    3. Press one button. nonoForge writes the whole thing into a folder of its own, and starts it so you can see it working. A note called START-HERE.txt goes in with it, explaining what each file is.

    The promise: nothing is installed, nothing is uploaded, there is no account, and it all keeps working with the internet switched off. If you delete the folder, the app is gone too — that is the whole footprint.

    Want to change it later? Open the folder and edit the files. They are ordinary HTML, CSS and Python, small enough to read, and the browser hiding behind them is yours.
